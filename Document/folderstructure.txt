6) สรุปหน้าที่ของโฟลเดอร์หลัก
==================================================

1. Client
   ใช้พัฒนาระบบฝั่งผู้ใช้หลักของห้องเรียน เช่น หน้า dashboard, ห้องเรียน, stream, assignment, event และประวัติข้อมูล

2. Server
   ใช้พัฒนาระบบฝั่ง backend สำหรับ API, authentication, database, notification, real-time socket และการจัดการข้อมูลทั้งหมดของระบบ

3. production-build
   รวมไฟล์สำหรับ deploy ระบบจริง เช่น Dockerfile, docker-compose และ nginx config

4. Document
   ใช้เก็บเอกสารสรุปโครงสร้างระบบ เอกสารเชิงเทคนิค และเนื้อหาสำหรับงานวิจัย

5. .nogic
   เป็นโฟลเดอร์ข้อมูลภายในที่มีไฟล์ฐานข้อมูลย่อย `nogic.db`

==================================================
7) โฟลเดอร์ที่ควรระวังเวลาทำงาน
==================================================

1. node_modules
   เป็น dependency ที่ติดตั้งอัตโนมัติ ไม่ควรแก้ไขโดยตรง

2. build
   เป็นผลลัพธ์จากการ build frontend ไม่ใช่ source code หลัก

3. logs
   เป็นไฟล์ log ระหว่าง runtime อาจมีขนาดใหญ่ขึ้นเรื่อย ๆ

4. uploads
   เป็นไฟล์ที่ระบบหรือผู้ใช้อัปโหลดจริง เช่น รูปภาพ เอกสาร และ banner

5. Document
   เป็นโฟลเดอร์เอกสาร หากต้องการให้ข้อมูลล่าสุดควรอัปเดตตาม source code จริงเสมอ
